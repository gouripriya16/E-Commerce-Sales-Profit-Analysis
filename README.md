# E-Commerce Sales & Profit Analysis Dashboard

## Project Overview
An interactive Power BI project developed to analyze e-commerce sales, profitability, customer behavior, product performance, and regional performance.

## Tools & Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX

## Data Preparation
- Imported CSV dataset.
- Handled missing values and errors.
- Removed duplicate records where appropriate.
- Corrected data types.
- Removed unnecessary spaces using Trim.
- Prepared the dataset for analysis.

## Dashboard Pages

### 1. Sales Overview
Analyzes overall sales, profit, orders, and monthly sales trends.

### 2. Product & Profit Analysis
Evaluates product performance and profitability.

### 3. Customer & Order Analysis
Analyzes customer segments, order patterns, and payment methods.

### 4. Regional & Channel Analysis
Compares regional sales, sales channels, and shipping performance.

## DAX Measures
- Total Sales
- Total Profit

## Key Features
- Interactive slicers
- Dynamic visualizations
- KPI cards
- Sales and profit analysis
- Professional dashboard design

## Outcome
Provides meaningful business insights and supports data-driven decision-making.
